# 화면 만들 때 규칙

- 화면 1(데이터 올리기)에서 [분류하기]를 누르면 화면 2(쓰인 분류 기준 확인)로, 화면 2에서 [결과화면 보기]를 누르면 화면 3(분류 결과)으로 이동하고, 화면 2의 [저장]과 화면 3의 [다운로드]는 같은 화면에 머무르며, 화면 3의 [처음 화면으로]를 누르면 화면 1로 이동하는 결과물만 만든다.
- 화면 1에서 파일도 URL도 없이 [분류하기]를 누르면 "업로드된 파일이 없습니다. 파일을 업로드 후 이용해주세요." 문구를 보여주고 화면 1에 그대로 머물게 만든다.

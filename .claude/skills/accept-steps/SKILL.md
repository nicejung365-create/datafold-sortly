# 수용 기준 확인 순서

## 언제 쓰나

- PRD.md 수용 기준대로 됐는지, 화면에서 뭘 눌러 확인하면 되는지 물을 때

## 무엇을 받나

- 지금 연 폴더 맨 위의 PRD.md("완성 기준" 항목들)

## 어떤 순서로 하나

1. 넘겨받은 것에 [확인할 화면 이름] 이 없으면 만들기 전에 먼저 묻는다
2. 수용 기준을 읽는다
3. 기준마다 해당 화면(1/2/3)과 버튼을 찾는다
4. 눌러야 할 순서와 확인할 문구로 정리한다

## 무엇을 내놓나

수용 기준마다 "화면 n에서 [버튼]을 누르면 ~이 보여야 함"을 번호 붙인 목록으로 적는다
같은 폴더의 template.md 양식대로 내놓는다
결과 맨 끝에 [프로젝트] 라고 한 줄 적는다

## 주의

- PRD.md 에 없는 내용은 지어내지 않는다

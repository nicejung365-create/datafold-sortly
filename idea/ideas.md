1. 지저분한 옛날 파일을 넣으면, 나 혼자 보기 편한 정리된 표 파일이 바로 나온다. (불편 1)
2. 여러 사람이 각자 올린 파일을 모으면, 매달 정해진 날에 하나로 합쳐진 표가 자동으로 나온다. (불편 1)
3. 정리가 끝난 표를 넣으면, 남에게 보여줄 정리 화면 하나가 나온다. (불편 1)
4. 새 파일이 폴더에 들어오면, 그 자리에서 바로 정리된 파일과 알림이 나온다. (불편 1)

5. 확인하고 싶은 SNS 주소들을 넣으면, 나 혼자 보는 알림 목록 한 장이 나온다. (불편 2)
6. 가족·팀의 계정을 등록하면, 매일 정해진 시간에 새 소식만 모은 정리본이 자동으로 나온다. (불편 2)
7. 하루치 알림을 모으면, 다른 사람도 보는 요약 화면 하나가 나온다. (불편 2)
8. 새 글이 올라오면, 그 순간 바로 내 폰에 알림 한 개가 나온다. (불편 2)

9. 지금 쓰는 구독 이름과 금액을 넣으면, 나 혼자 보는 구독 목록표가 나온다. (불편 3)
10. 가족 구독을 각자 입력하면, 매달 결제일마다 전체 목록이 자동으로 다시 정리돼 나온다. (불편 3)
11. 한 달치 구독 내역을 넣으면, 가족과 같이 보는 화면 하나가 나온다. (불편 3)
12. 결제일이 다가오면, 그날 바로 "이번 주 결제 예정" 알림이 나온다. (불편 3)

13. 한 번 만든 디자인 요소를 넣어두면, 다음에 나 혼자 바로 꺼내 쓰는 모음 파일이 나온다. (불편 4)
14. 팀이 자주 쓰는 형식을 등록해두면, 새 작업을 시작할 때마다 정해진 틀이 자동으로 채워져 나온다. (불편 4)
15. 완성된 디자인들을 모으면, 남에게 보여줄 견본 화면(갤러리)이 나온다. (불편 4)
16. 비슷한 디자인을 또 만들려 하면, 그 순간 "전에 만든 것 있어요" 알림과 예전 파일이 나온다. (불편 4)

17. 궁금한 질문 하나를 넣으면, 나 혼자 보는 답 정리표 한 장이 나온다. (불편 5)
18. 팀이 자주 묻는 질문들을 모아두면, 매주 정해진 날에 답을 모은 정리본이 자동으로 나온다. (불편 5)
19. 여러 사이트에서 얻은 답을 모으면, 남에게 보여줄 비교 화면 하나가 나온다. (불편 5)
20. 새로 궁금한 게 생기면, 그 자리에서 바로 답 하나가 나온다. (불편 5)

21. 관심 주제를 넣으면, 나 혼자 보는 오늘 뉴스 목록 한 장이 나온다. (불편 6)
22. 가족·팀의 관심 주제를 모으면, 매일 아침 정해진 시간에 모두를 위한 뉴스 모음이 자동으로 나온다. (불편 6)
23. 하루치 뉴스를 모으면, 남과 같이 보는 요약 화면 하나가 나온다. (불편 6)
24. 중요한 뉴스가 뜨면, 그 순간 바로 알림 한 개가 나온다. (불편 6)

25. 오늘 먹은 것과 한 일을 넣으면, 나 혼자 보는 하루 기록표가 나온다. (불편 7)
26. 가족 건강 기록을 각자 넣으면, 매주 정해진 날에 전체 상태 정리본이 자동으로 나온다. (불편 7)
27. 한 주치 기록을 모으면, 병원이나 가족에게 보여줄 화면 하나가 나온다. (불편 7)
28. 영양제 먹을 시간이 되면, 그 순간 바로 "지금 드세요" 알림이 나온다. (불편 7)

29. 각 오픈마켓 주문 내역을 넣으면, 나 혼자 보는 통합 구매 목록표가 나온다. (불편 8)
30. 가족 구매 내역을 각자 올리면, 매달 정해진 날에 전체 지출 정리본이 자동으로 나온다. (불편 8)
31. 한 달치 구매 내역을 모으면, 가계부처럼 같이 보는 화면 하나가 나온다. (불편 8)
32. 새 주문이 들어오면, 그 자리에서 바로 "이번 달 지출 얼마" 알림이 나온다. (불편 8)

33. 만들고 싶은 노트 틀을 넣으면, 아이 혼자 쓸 수 있는 무료 필기 파일이 나온다. (불편 9)
34. 가족이 같이 쓸 항목을 등록해두면, 공부 시작할 때마다 정해진 틀이 자동으로 채워져 나온다. (불편 9)
35. 아이가 쓴 노트를 모으면, 부모도 같이 볼 수 있는 화면 하나가 나온다. (불편 9)
36. 아이가 저장을 누르면, 그 즉시 다음에도 이어 쓸 수 있는 파일이 나온다. (불편 9)

37. DOC 파일을 넣으면, 나 혼자 바로 쓸 수 있는 HWP 파일이 나온다. (불편 10)
38. 여러 사람이 DOC 파일을 모아 올리면, 정해진 시간마다 HWP로 바뀐 파일 묶음이 자동으로 나온다. (불편 10)
39. 바꾼 파일들을 모으면, 남이 내려받을 수 있는 변환 페이지 하나가 나온다. (불편 10)
40. DOC 파일이 생기자마자, 그 순간 "HWP로 바꿨어요" 알림과 변환된 파일이 나온다. (불편 10)

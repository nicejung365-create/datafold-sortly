# 넣으면 나온다

한 줄 : 표·글 파일 또는 게시물 URL을 넣으면 → 생애주기·분야·정보유형 태그가 붙은 콘텐츠 소재 카드 여러 장이 나온다.

- 입력 : 표·글 파일을 올리거나, 게시물 URL(인터넷 주소)을 입력한다. (근거: scope.md 넣을 기능 7)
- 처리 : 올린 데이터(파일 내용 또는 URL 페이지 내용)를 읽어서, 정해진 기준(없으면 새로 만든 기준)으로 생애주기·분야·정보유형 칸을 채운다.
- 출력 : 카드 여러 장 — 데이터 하나당 카드 1장, 카드 안에 내용 요약 + 생애주기·분야·정보유형 태그 3개(읽기 전용), 화면 하단에 전체 다운로드 버튼 1개. (기존에는 카드마다 수정 버튼도 있었으나, 넣을 기능을 3개 이하로 좁히면서 수정 기능은 빠짐)
- 모양 : 만들어주는 도구 — 데이터를 넣으면 실제로 가공(분류)해서 새 결과물을 만들어 내기 때문.
- 잘못 넣었을 때 : 파일도 URL도 넣지 않고 실행하면, "올라온 파일이 없습니다. 표·글 파일을 먼저 올려 주세요."라고 화면에 알려준다. (URL 추가에 맞춰 문구를 바꿀지는 확실하지 않음 — 질문 필요)
